# Sistema Help Desk

Aplicación de escritorio en Python para administrar tickets de soporte, activos y técnicos. Permite asignar técnicos, actualizar estados, consultar reportes y generar PDF de tickets.

Este proyecto es un trabajo académico requerido en la carrera de **Analista funcional de sistemas informáticos**.

## Ejecución

1. Instala Python y las dependencias:

   ```bash
   python -m pip install -r requirements.txt
   ```

2. Inicia la aplicación:

   ```bash
   python main.py
   ```

Los archivos JSON de tickets, activos y técnicos se generan localmente cuando se necesitan y no se incluyen en Git porque pueden contener información sensible.
